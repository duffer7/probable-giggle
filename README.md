# 🎯 probable-giggle

## 📖 Overview
Personal repository for various tasks and exercises aimed at continuous self‑development.

## 🗂️ Target
Collect and organize all valuable tasks in one place to prevent them from being forgotten or lost.

## 📌 Rules
- Each task lives in its own directory.
- Clear naming convention for directories (e.g., `sql-basics`, `node-api`).
- Each task should include a `README.md` with description, requirements, and solution.

## 🛠️ Stack
Primarily:
- **JavaScript / TypeScript**
- **Node.js**

Additional tools and technologies may be added as tasks evolve.
