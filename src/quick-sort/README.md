# 🌀 Quick Sort

## 📖 Description
Splits an array into subarrays based on a pivot element, then recursively sorts the subarrays.  
An efficient and widely used algorithm.

## ⚡ Complexity
- **Average case:** O(n log n)  
- **Worst case:** O(n²) (with a poor choice of pivot element)

## 🎯 Usage
Suitable for large arrays where efficiency is critical.
