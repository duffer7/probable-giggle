# Sliding Window Algorithm (TypeScript)

## 📌 Overview

The **sliding window** technique is a powerful method for solving problems that involve subarrays or substrings.  
It reduces time complexity by avoiding repeated computations and "slides" a window across the input data.

## ⚡ Complexity

- **Time Complexity**: `O(n)` — each element is processed once as the window slides.
- **Space Complexity**: `O(1)` — only a few variables are used regardless of input size.

## ✅ Benefits

- Efficient for problems with contiguous sequences
- Avoids redundant calculations
- Easy to implement and generalize
